the first time

macOS will stop you once. Here is why.

nimo is not signed with Apple's $99-a-year certificate, so the first time you open it macOS says it cannot check it. That is a statement about a receipt, not about the app — every line of it is on GitHub, and the copy you download is built there, in the open, by a script you can read.

  1. Download Nimo.app.zip and double-click it to unzip.
  2. Drag Nimo into your Applications folder.
  3. Right-click it (or Control-click) and choose Open. Not double-click — right-click. Then Open again in the dialog.
  4. That is once, for ever. A face appears in your menu bar.

If you would rather not take anyone's word for it: app/build.sh in the repository is the whole build, forty lines of it, and the release is put together by GitHub's own machines from the tag you can see.

how min tidy works

Four steps. Four chances to say no.

One command walks the whole thing. Nothing runs until you say so, and nothing is remembered except how to undo it.

1

Your desktop

Counted by kind, then moved into one folder — and logged file by file.

2

Your dock

Listed with Apple's own additions marked, so you can see what you never chose.

3

Your wallpaper

From the ones your system already ships with, flipped through one at a time on your own screen. nimo never touches the network.

4

Your preferences

Five small groups of defaults write — each key's old value read and kept, so it can go back.

and not only on a mac

Windows, without loosening a thing.

Under Git Bash, MSYS2 or Cygwin, $HOME is already C:/Users/<name> — so the rule that keeps nimo inside your home folder holds there untouched. It finds the Desktop after Windows has moved it into OneDrive, is not fooled by the empty one left behind, and looks for junk under AppData rather than ~/Library.

It leaves the Recycle Bin alone, because that is an index as well as a folder and half-deleting it helps nobody. And WSL is treated as Linux on purpose: its home is a Linux home, the Windows one sits outside it, and reaching over there would mean widening the one guard that never widens.

what nimo will and will not do

Six promises, and the code to check them against.

Nothing happens without a yes

Every command that changes something shows what it is about to do, and waits.

Everything is undoable

Desktop moves logged one by one. The dock exported first. Every preference read — value and type — before it is overwritten.

Only inside your home folder

Any path outside $HOME is refused, and so is $HOME itself. The guard is four lines long.

No sudo. Ever.

If something would need administrator rights, nimo skips it and says so.

Nothing is downloaded

Wallpapers come from what your system already ships. nimo never reaches the network.

Small enough to read

One script and eleven short libraries. Fifteen minutes and you know everything it can do.

how it is kept honest

Every promise here is a job that fails.

A hundred and seventy-six checks run against a fake computer in /tmp with its own fake home — including the arrow-key picker, driven by simulated keystrokes, and a full clean where the promised number is compared against the freed one. Your real files are never read.

The dock, the wallpaper and the preferences only ever run on a Mac, which used to make them the parts nobody could test. A hundred and thirteen more checks put fake defaults, osascript, pmset and uname in front of the real ones and run the real code against them — for macOS and for Git Bash alike — the right apps leave the dock and the rest keep their order, the backup is written before anything changes, --restore brings it all back, and no line anywhere reaches for sudo.

That suite has found three real bugs so far. pmset reports discharging, which contains charging, so a battery on its way down was being called plugged in. A guard written as "$(printf '\n')" collapsed to an empty string, so it matched every value instead of the structured ones. And two runs inside one second landed on the same log name, where the second truncated the first and took the only record of how to undo it. Each one now has a test standing on it.
