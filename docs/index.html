a command line tool for macOS

Make your computer
feel better.

nimo clears your desktop, trims your dock, calms your wallpaper and gives you the disk back. Every step asks first. Every step can be undone.

the way in

Type min. Press enter.

On its own, nimo is a menu rather than a wall of help. Arrow to what you want and press enter. Piped into anything, the same command prints plain help instead — nothing here needs a clever terminal to work.

min desktop undoable, file by file

Everything on your desktop moves into Desktop/Tidy/, sorted by what it is. Nothing is deleted. Nothing is renamed — if a name is taken, the new one becomes invoice 2.pdf. Hidden files stay put.

Every single move is written down, so min desktop --undo puts all forty-seven back exactly where they were, folders and all.

min dock you decide, never nimo

nimo lists what is down there and marks what Apple put in for you. Tick the ones that should go. The apps stay installed — only the icons leave. Your whole dock is exported first, so --restore brings back exactly what you had.

min clean and only then, the disk

Sixteen places where junk piles up, split in two. Safe to clean is caches your apps rebuild by themselves. Worth a look is measured, shown, and never touched — not even with --yes.

After cleaning, nimo measures again and tells you what was actually freed, not what it hoped to free.

what nimo will and will not do

Six promises, and the code to check them against.

Nothing happens without a yes

Every command that changes something shows what it is about to do, and waits.

Everything is undoable

Desktop moves logged one by one. The dock exported before it is touched. The old wallpaper written down.

Only inside your home folder

Any path outside $HOME is refused, and so is $HOME itself. The guard is four lines long.

No sudo. Ever.

If something would need administrator rights, nimo skips it and says so.

Nothing is downloaded

Wallpapers come from the ones macOS already ships with. nimo never reaches the network.

Small enough to read

One script and eleven short libraries. Fifteen minutes and you know everything it can do to your Mac.

how it is kept honest

The bash 3.2 promise is a job that fails.

Eighty checks run against a fake computer in /tmp with its own fake home: every command and flag, the safety guard, the arrow-key picker driven by simulated keystrokes, the desktop sorted and then fully undone, and a complete clean where the promised number is compared against the freed one. Your real files are never read.

Every push runs them on GitHub Actions — including on macOS under /bin/bash, the actual 3.2 that ships with the system. The compatibility claim on this page is not a claim.

get it

One clone, one install.

git clone git@github.com:danielkopa/nimo.git ~/nimo && cd ~/nimo && ./install.sh

Then min tidy. Or min preview first, which cannot change anything at all. Later, min update pulls the newest version and man min explains the rest.
