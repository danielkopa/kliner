send

Any file, to any @username.

Full quality, never compressed. To a Mac nearby it goes straight across; to anyone else it goes through kliner.app, encrypted on your Mac before it leaves.

  • Encrypted on your Mac with ChaCha20-Poly1305, a fresh key for every file.
  • That key is sealed to the receiver, so kliner.app only ever holds ciphertext.
  • Kept for seven days at most.

promises

Six promises, and the code to check them against.

  • Never asks for your password

    No sudo, ever. Anything that would need an administrator is left alone, and Kliner says so.

  • Only inside your home folder

    Anything outside your home folder is refused, and so is the home folder itself.

  • Nothing happens without a yes

    Whatever would change something shows you what it is about to do, and waits.

  • Everything can be undone

    Moves are logged file by file, the Dock is saved before it is touched, old settings are kept. Emptying the Trash is the one exception, and it says so.

  • Preview changes nothing

    --dry-run and Preview show what would happen, and change nothing at all.

  • Open source, MIT

    Every line is on GitHub, to read, build and check.

for the terminal

Underneath, a tool you can read.

Kliner is a window on min, a small bash tool that comes inside the app. What the window changes, it changes by running min, so a terminal gets the same commands, the same questions and the same undo.

Add --dry-run to anything: it shows what would happen, and changes nothing.
